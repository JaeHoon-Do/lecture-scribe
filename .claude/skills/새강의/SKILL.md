# /새강의 <폴더이름>

강의 폴더 하나를 만들고, 사용자가 시간만 채우면 되는 `timeline.txt` 를 넣어 준다.
인자 `$ARGUMENTS` = 폴더 이름 (예: `피부감각기_피부종양, STD, 전신질환의 피부증상(결체조직질환)`). 따옴표는 벗긴다.
인자가 없으면 폴더 이름을 물어본다 (권장 형식: `<과목>_<수업이름들>`).

## 절차

1. 대상 = `<repo>\<폴더이름>`.
   - 이미 있으면 **아무것도 덮어쓰지 않고** 현재 상태(lecture.json/timeline.txt/자료 파일/output 유무)만 보고하고 끝낸다.
2. 만든다: `<폴더>\`, `<폴더>\_work\`, `<폴더>\output\`.
3. `<repo>\templates\timeline.txt` 를 `<폴더>\timeline.txt` 로 복사한다 (UTF-8 그대로).
4. 사용자에게 다음을 안내하고 끝낸다:
   - 폴더에 넣을 파일: 녹화본 **mp4 1개** (파일명 `YYYYMMDD_교시_과목_교수.mp4` 형식이면 날짜·과목·교수를 자동 인식), 수업별 **오늘 자료 pdf(+pptx)**, 작년 **필기** pdf 와 **한장** pdf (있으면; 파일명에 `필기`/`한장` 이 들어가면 자동 매칭).
   - `timeline.txt` 를 열어 수업별로 `시작 ~ 끝  수업이름` 한 줄씩 채운다 (HH:MM:SS, 녹화본 기준).
   - 다 되면 `/필기 "<폴더이름>"`.

## 주의
- 폴더 이름의 쉼표·괄호·공백은 그대로 둔다 (경로는 항상 따옴표로 감싼다).
- 여기서는 lecture.json 을 만들지 않는다 — `/필기` 가 timeline.txt 와 실제 파일 목록을 보고 만든다.
